# Michigan Phenology

A small Next.js site for Michigan seasonal timing and live phenology decision tools.

## Michigan Bloom Tracker map data

The `/bloom-tracker` geographic comparison surface uses committed state geometry derived from U.S. Census Bureau TIGERweb data. Great Lakes shoreline/water geometry is derived from Natural Earth 1:50m lakes data (public domain). Bloom destination and regional-wave markers use coordinates from the bloom model rather than the map source.
