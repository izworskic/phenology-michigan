# Almanac publishing resilience

The numerical archive remains authoritative. The optional written note uses the authorized Fall Color credential if configured, then the existing Anthropic key only on explicit authentication rejection. Any other failure uses a labeled deterministic note from available banked numerical values and usual calendar windows. A snapshot without numerical evidence or a failed snapshot write produces no new note; the numerical/archive failure remains visible. Source times are not present in the existing snapshot, so the fallback describes snapshot values without claiming direct current field observations. Existing storage, schedules and URLs remain unchanged. No credentials are copied or logged. No new dependencies or paid service. Existing same-day model notes are not replaced by a degraded fallback on a retry. Actual source-time validation is a separate follow-up.
