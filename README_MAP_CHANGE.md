# Bloom Tracker map redesign

This branch promotes the map from a locator into an interpretive decision surface.

- CARTO Voyager supplies geographic context.
- Active bloom uses vivid stage colors and a destination-status glow.
- Off season explains the timing sequence in plain language.
- The map is visually ordered ahead of the ranked destination list.
- Map copy states that glow is destination status, not mapped flower coverage.
- CARTO/OpenStreetMap attribution remains visible.
